# IRODORI Design System v1

## 1. ブランド方針

IRODORIは、育児用品を「探す・比べる・納得して選ぶ」ためのメディア兼比較サイト。

目指す方向性：

- 見た目は Blossom39 のように軽く、上品で、商品が自然に並ぶ
- 探しやすさは Babylist のようにカテゴリ・条件・ブランドから辿れる
- 比較機能は価格.comのように分かりやすく
- 診断導線はSUUMOのように、生活スタイルから選べる

単なる比較サイトではなく、ブランド公式サイトのように見える育児用品プラットフォームを目指す。

## 2. デザイン原則

優先順位：

1. 見やすい
2. 探しやすい
3. 比較しやすい
4. 上品
5. おしゃれ

やってはいけないこと：

- 太字を使いすぎない
- カード感を強くしすぎない
- `box-shadow`を多用しない
- 枠線で囲いすぎない
- 情報を詰め込みすぎない
- 商品一覧を重い比較表のように見せない
- ページごとに文字サイズ・余白・角丸を変えすぎない

## 3. カラー

基本カラー：

- 本文：`#444444`
- 見出し：`#2f2f2f`
- 補足テキスト：`#888888`〜`#999999`
- 背景：`#ffffff`
- 薄い背景：`#fafafa`
- 区切り線：`#efefef`
- ブランドグリーン（選択中・主要ボタン）：`#80BD9E`
- ブランドグリーン hover：`#6EAA8B`
- 淡いグリーン背景：`#eef7f3`
- 価格：`#444444`

価格は原則赤にしない。セール・注意・エラーなど、本当に意味がある場合のみ赤を使う。

## 4. フォント

基本：

- 本文・読み物：`"Mamelon", "Mamelon Hi Regular", "Mamelon 4 Hi Regular", "Kiwi Maru", "Noto Sans JP", "Hiragino Maru Gothic ProN", "Yu Gothic", "Meiryo", sans-serif`
- 見出し・カテゴリ名・ブランドコピー・商品名：本文と同じマメロン優先の丸みがあるフォントスタックを使用する
- 価格・ボタン・チップ・フォーム・ナビゲーション：`"Noto Sans JP", "Hiragino Kaku Gothic ProN", "Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif`
- body：14px / weight 400 / line-height 1.6
- letter-spacing：0.03em

マメロンを見出し、英字セクション見出し、TOPコピー、カテゴリ名、ブランド説明、商品名を中心に使用する。価格や操作UIは数字と短いラベルの判読性を優先してUIゴシックを使用し、スマホでも細すぎるウェイトを使わない。基本ウェイトは400、大見出しも500までとする。フォントファイルが未配置の場合も、後続のフォールバックで表示を崩さない。

見出し：

- H1：28px〜36px / weight 600
- H2：22px〜28px / weight 600
- H3：18px〜22px / weight 600
- 小見出し英字：12px / letter-spacing 0.12em / color `#999`

商品一覧：

- ブランド名：11px〜12px / weight 400 / color `#888`〜`#999`
- 商品名：13px〜14px / weight 500 / color `#333`〜`#444`
- 価格：12px〜14px / weight 500 / color `#444`
- 商品タグ：11px / weight 400 / color `#FF420E` / 白背景 + 同色の1px枠
- 補足情報：12px〜13px / weight 400 / color `#888`〜`#999`

太字は見出し・重要な商品名まで。通常テキストやサイドバー項目に bold を使いすぎない。

## 5. 余白ルール

基本単位：

- 4px
- 8px
- 12px
- 16px
- 24px
- 32px
- 40px
- 64px

商品カード内の推奨余白：

- 画像 → ブランド名：16px〜20px
- ブランド名 → 商品名：4px
- 商品名 → 価格：6px〜8px
- 価格 → タグ：8px〜10px
- タグ → クイックビュー：12px〜14px
- クイックビュー → 購入リンク：8px〜10px
- 購入リンク → 比較チェック：8px

現在のベビーカー一覧では、ブランド名・商品名・価格・タグの間が空きすぎないようにする。商品カードの高さを揃えるためだけの `min-height` は原則使わない。

## 6. 角丸

基本：

- 商品画像：16px
- ヒーロー画像：20px〜24px
- ボタン：999px または 16px
- チップ：999px
- 入力欄：8px〜12px
- 商品カード全体を囲う大きな角丸は原則使わない

商品一覧では、カード全体ではなく画像にだけ角丸を付ける。

## 7. 商品一覧ページ

目的：

ユーザーが商品を探し、比較候補を見つけるページ。

見た目：

- Blossom39のように軽い商品グリッド
- 画像とテキストを自然に並べる
- 商品カード感を出しすぎない
- 商品画像を主役にする
- 情報は詰め込みすぎず、必要なものだけ見せる

基本表示：

- 順位ラベル
- 商品画像
- ブランド名
- 商品名
- 価格
- タグ
- クイックビュー
- 楽天 / Amazon / Yahoo! / 公式リンク
- 比較チェック

商品一覧で出しすぎないもの：

- 長い説明文
- 細かすぎるスペック
- 大量のレビュー風表示
- 架空の星評価
- 強いカード枠
- 大きな影

商品詳細で見せるもの：

- 重量
- 対象月齢
- サイズ
- 仕様表
- 口コミ要約
- 向いている生活シーン
- 注意点

## 8. 商品一覧の密度

PC：

- ベビーカー一覧では、左サイドバーありでもPCは4列を基本
- 左サイドバーなしのTOP・特集商品グリッドは4列を基本
- TOPのカテゴリ別おすすめは最大4商品とし、PCは4列×1行、スマホは2列×2行で完結させる
- 商品画像が大きすぎる場合は列幅・画像比率を調整
- 余白は広すぎず、詰めすぎず

スマホ：

- 基本は2列。比較情報や説明文が多い表示のみ1列を許容
- 絞り込みはボタンまたはドロワー
- 商品画像は見やすく
- 比較バーが商品に被らないようにする

商品カード内は、縦の余白をコンパクトに保つ。

## 9. 左サイドバー

目的：

Babylistのように、カテゴリ・タイプ・シーン・ブランドなどから探せるようにする。

使用ページ：

- ベビーカー一覧
- 抱っこ紐一覧
- チャイルドシート一覧
- ヒップシート一覧
- 将来のカテゴリ一覧

ブランドページには原則サイドバーを置かない。ブランドページは世界観を見せるページ。

サイドバー仕様：

- PCでは左固定カラム
- スマホでは絞り込みボタンから開閉
- 各グループはアコーディオン
- 初期状態はカテゴリのみ開いてもOK
- ブランドなど長い項目は最初から全表示しない
- 内部スクロールバーは原則出さない
- 「もっと見る」またはアコーディオン展開で対応

見た目：

- 背景は白
- 区切り線は`#efefef`
- 文字色は`#444`
- 補足や件数は`#999`
- チェックボックスは小さめ
- 太字にしすぎない

## 10. ブランドページ

目的：

ブランドの世界観と商品ラインナップを見せるページ。

構成：

- パンくず
- ブランドロゴ + ブランド説明
- ヒーロー画像
- 商品ラインナップ

ブランドページでは、左サイドバーは原則なし。商品一覧は軽いグリッドで表示。比較要素を強くしすぎない。

表示情報：

- 商品画像
- カテゴリまたはブランド名
- 商品名
- 価格

スペックを出す場合はかなり控えめにする。

## 11. 商品詳細ページ

目的：

購入判断のために情報を整理するページ。

構成：

PC：

- 左：商品画像・サムネイル
- 右：ブランド名・商品名・価格・購入リンク・概要・仕様表

スマホ：

- 商品画像
- 商品名
- 価格
- 購入リンク
- 概要
- 仕様表

方針：

- Babylistのように2カラムで見やすく
- ただしカートUIは真似しない
- アフィリエイトサイトとして、楽天 / Amazon / Yahoo! / 公式への導線を表示
- URLがないリンクは非表示
- ダミーレビューや架空の星評価は入れない

## 12. TOPページ

目的：

カテゴリ・特集・診断・ランキングへ自然に誘導するページ。

方針：

- 世界観はブランドサイト寄せ
- 導線は分かりやすく
- 商品一覧ページと同じ色・余白・角丸を使う
- TOPだけ派手すぎるデザインにしない
- ヒーロー、カテゴリ、特集、ランキングで共通ルールを使う

TOPに使う要素：

- ヒーローバナー
- カテゴリ導線
- シーン別特集
- ブランド特集
- 人気ランキング
- 診断導線

TOPの主要セクション見出しは共通クラスで管理し、PCは32px前後、スマホは23pxを基準とする。font-weightは400、letter-spacingはPCで0.08em、スマホで0.06emとし、「カテゴリから探す」「暮らしのシーンから探す」「カテゴリ別おすすめ」で個別に太さやサイズを変えない。英字ラベル、見出し、サブタイトルは中央揃えにする。

## 13. ボタン・チップ

ボタン：

- ページ導線とクイックビューは角丸8pxの四角枠
- 強い影は使わない
- primaryはブランドグリーン
- secondaryは白背景 + `#efefef` border

チップ：

- 角丸999px
- 背景は`#f7f7f7`または`#eef7f3`
- 文字は13px〜14px
- 太字にしすぎない

検索、絞り込み、選択中タブはpill型を維持する。ページ導線とクイックビューは四角枠にして、操作の役割が混ざらないようにする。

## 14. 比較UI

比較チェック：

- 商品カード下部に控えめに表示
- チェックボックスと「比較」テキスト

比較バー：

- 0件では非表示
- 1件以上で表示
- 商品一覧や画像に被らないようにする
- PC/スマホともに下部paddingを確保
- 主張しすぎない

長いページでは右下に控えめなBack to Topボタンを表示する。600px以上スクロールしたときだけ表示し、比較バーが表示されている場合は重ならない位置まで上げる。

## 15. 実装ルール

- 共通カラー・余白・角丸はCSS変数に寄せる
- ページごとにバラバラの値を直接書かない
- 既存のSupabase取得処理を壊さない
- 管理画面・画像登録処理はデザイン変更の対象外
- 商品リンク・アフィリエイトリンクを壊さない
- 参考サイトのCSSをそのままコピーしない
- 参考サイトは雰囲気・密度・余白・文字サイズの参考に留める

## 16. 今後Codexへ依頼するときのルール

Codexへデザイン修正を依頼する場合は、必ず以下を前提にする。

> `irodori-design-system.md` を確認し、そのルールに従ってください。

新しいUIを作る場合も、まずこのデザインシステムに合っているか確認する。
