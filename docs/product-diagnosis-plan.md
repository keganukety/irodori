# 商品診断機能の準備メモ

このメモは将来の診断機能に向けた設計案です。現時点では診断ページや判定ロジックは実装していません。

## 現在利用できるカラム

現行の公開一覧・詳細ページで利用している、診断条件に使える可能性が高いカラムです。

- `id`
- `name`
- `brand`
- `category`
- `product_type` または `type`
- `target_age`
- `weight_kg` または `weight`
- `price_yen`
- `feature_tags`
- `rank_no`
- `product_size` / `size` / `dimensions` / `product_dimensions`
- `folded_size` / `folding_size` / `storage_position`
- `basket_capacity` / `shopping_basket` / `basket`
- `load_capacity` / `max_load` / `max_weight`

上記以外の寸法系カラムはプロジェクト内の型候補として扱っていますが、実際に全商品へ値が入っているかは未確認です。

## feature_tagsで一時対応できる条件

`feature_tags` に以下のような語が入っている場合は、初期版の診断条件として利用できます。

- 新生児から使える: `新生児OK`, `新生児`, `1ヶ月`
- 軽量: `軽量`, `4kg台`, `5kg台`
- コンパクト: `コンパクト`, `折りたたみ`, `省スペース`
- 電車移動向け: `電車移動`, `駅`, `改札`, `軽量`
- 軽自動車向け: `軽自動車`, `コンパクト`, `折りたたみ`
- 飛行機・旅行向け: `旅行`, `トラベル`, `機内`, `コンパクト`
- マンション向け: `コンパクト`, `軽量`, `折りたたみ`
- ワンオペ向け: `片手`, `軽量`, `自立`, `ワンタッチ`
- 荷物が多い人向け: `大容量`, `バスケット`, `収納`
- 価格重視: `price_yen` の数値で判定

ただし、タグ表記の揺れがある場合は判定漏れが起きます。初期版は「推測判定」として扱うのが安全です。

## 足りないカラム

診断精度を上げるには、以下のような専用カラムがあると扱いやすくなります。

- `is_newborn_usable`
- `is_lightweight`
- `is_compact`
- `is_train_friendly`
- `is_small_car_friendly`
- `is_travel_friendly`
- `is_apartment_friendly`
- `is_one_parent_friendly`
- `has_large_basket`
- `folded_width_cm`
- `folded_depth_cm`
- `folded_height_cm`
- `basket_capacity_kg`
- `one_hand_fold`
- `self_standing_when_folded`

## Boolean化したほうがよい条件

以下はタグや文章から毎回推測するより、Booleanカラムで持つほうが安定します。

- 新生児から使える
- 軽量
- コンパクト
- 電車移動向け
- 軽自動車向け
- 飛行機・旅行向け
- マンション向け
- ワンオペ向け
- 荷物が多い人向け
- 自立収納できる
- 片手でたためる

## 将来の診断質問案

1. 主に使う月齢は？
   - 新生児から
   - 7か月頃から
   - 1歳頃から

2. よく使う移動手段は？
   - 徒歩
   - 電車
   - 車
   - 飛行機・旅行

3. 重視したいことは？
   - 軽さ
   - 走行性
   - コンパクトさ
   - 荷物の入れやすさ
   - 価格

4. 収納場所は？
   - 玄関に置く
   - 車に積む
   - マンションの共用部やエレベーターをよく使う

5. 使う人の状況は？
   - ワンオペが多い
   - 兄弟連れが多い
   - 荷物が多い

## 判定ロジック案

初期版では、各条件にスコアを付けて合計点で並べる方式が扱いやすいです。

- 必須条件に合わない商品は除外
- 希望条件に合う商品へ加点
- `rank_no` が近い、または上位の商品へ軽く加点
- `price_yen` は価格重視時のみ加点・減点に使う
- `feature_tags` 判定は一時対応として使い、Booleanカラムが追加されたら置き換える

## 推測である部分

以下は現在のDB値を完全確認できていないため、推測を含みます。

- `feature_tags` の表記揺れ
- 寸法系カラムの実在と入力率
- 収納サイズ、耐荷重、バスケット容量の入力形式
- 「電車移動」「軽自動車」「旅行」などの用途タグの網羅性

診断機能を本実装する前に、Supabase上でproductsテーブルのカラム一覧と代表データを確認してください。
