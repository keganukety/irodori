# copyright-and-acquisition-policy — 著作権・取得・保存ポリシー(正本)

区分ラベル: **[C] = Confirmed Principle / [P] = Proposed Default / [O] = Open Decision / [U] = Unverified**

## 1. 保存してよいもの・いけないもの [C]

| してよい | してはいけない |
|---|---|
| 事実(数値・仕様・発売日)の抽出と記録 | 外部記事の全文・長文の転載 |
| IRODORIの言葉による短い構造化要約 | 比較表・画像・グラフの複製 |
| URLへ戻るための出典メタデータの保存 | 口コミ本文の大量保存 |
| 必要最小限の短い直接引用(引用と要約を区別し、出典明記) | 引用と要約の混在(どこまでが引用か不明な記録) |
| 口コミのテーマ別傾向・観測件数の記録 | 個人を特定できる情報(投稿者名・ID・プロフィール等)の保存 |

- `evidence_claim.value_raw` に入れてよいのは、値の照合に必要な最小限の語句
  (数値+単位+直近の修飾語程度)まで [P]。文単位・段落単位の転記をしない [C]。
- 直接引用を使う場合は `quote: true` を付け、引用符・出典を明示する [P]。

## 2. 他媒体の評価表現の扱い [C]

- 他媒体独自の評価ラベル・賞(「ベストバイ」等)をIRODORI独自評価として表示しない。
- 他媒体の見解に言及する場合は「◯◯(媒体名)は〜と評価している」という帰属付きの
  事実としてのみ扱い、`evidence_claim` (claim_class: `editorial_opinion`) に記録する。
- メーカーの宣伝表現は `manufacturer_claim` とし、客観的事実として断定しない。

## 3. 取得手段 [C](本段階) / [U](規約)

- 第2段階のローカル試作では、Webスクレイピング・自動巡回・外部取得サービスへの接続を行わない。
- 各媒体(価格.com・マイベスト・たまひよ等)の利用規約、取得・転載・データ利用の可否は
  **Unverified**。確認せずに「取得してよい」と判断しない。
- Apify・Firecrawl 等の外部サービスの公式性・ライセンス・安全性・更新状況も Unverified。
  過去の会話・記憶を根拠に確定しない。必須依存にしない(Open Decision #18)。

## 4. 法務確認が必要な事項(公開運用前) [C]

以下は本スキル群では判断できない。公開運用の前に規約確認および専門家(弁護士等)への
相談を必要とする。この確認が済むまで、該当データを含む成果物は
`publication_status: review_required` を超えない。

1. 引用の要件(主従関係・必然性・出所明示)を満たす運用ルール
2. 口コミの傾向要約が翻案にあたらないか
3. 価格・スペックデータの利用と各媒体の利用規約・データベース著作権
4. スクレイピング/自動取得の可否(媒体ごと)
5. メーカー画像・取説PDFの取り扱い

## 5. 個人情報 [C]

- 投稿者名・ハンドル名・ユーザーID・顔写真・居住地など、個人の特定につながる情報を
  `source_record` / `evidence_claim` / `review_theme_summary` のいずれにも保存しない。
- 「30代・第一子」のような属性の傾向は、個人と結びつけない形でのみ記録できる [P]。
- 保存前チェックとして `pii_check`(→ `data-contracts.md` の review_theme_summary)を通す。
